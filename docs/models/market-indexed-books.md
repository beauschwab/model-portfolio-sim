This explicit owner selects actual dated indexed pricing for bound loan rows inside one native portfolio/cache owner. Unbound loan/debt rows continue through the existing native incremental pricer. Python transports the raw request and formats the native row union; it does not calculate a second financial union. The owner, month-360 successor and per-call runtime control are applied locally in 0.29.8, and matching official native builds and component gates pass. Complete installed-default acceptance is being rerun after a separate test-fixture repair. Saved libraries/cohorts, physical accounting, capital/FTP, empirical validation and joint market dynamics remain unsupported. Local source application and builds do not deploy this owner.

`graph-1` operations `create_market_indexed_books` and `price_market_indexed_books` carry `market-indexed-books-1`. Complete original/current normalized rows and complete `market-indexed-graph-1` sources are supplied per binding, together with `original_native_pv_quote_reconciliation-1` review identity.
