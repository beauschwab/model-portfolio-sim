# New vertical admission contract (under validation)

The policy `combined_gross_state_10k-1` has scalar and separate aggregate domains. Each scanned amount is finite with `abs(amount)<=10000`; each defined gross lane sums absolute amounts and rejects `>10000` without tolerance/clamp. These are additional narrow public-schema restrictions, not changes to the frozen source or old entrypoints.

Supplied aggregate: account cash/equity/cash_floor/capital_deductions; position balance/book_adjustment/opening_accrued/allowance/commitment/pledged_face; every retained dated event's principal/cash_interest/accrued_interest/book_amortization/fees; every raw recognition segment's accrued_interest/book_amortization; every distinct registry source's three opening investor principals plus actual acquisition cost. Supplied values are scanned once; duplicate run references do not charge source raw twice. This deliberately conservative gross bound counts cash and recognition separately; it is not a future-state certificate.

Unweighted native runtime lanes (each independently <=10k): (1) all7 slots and all claim book P/A/B plus cumulative cash/original-EIR/reviewed-income; (2) all7 borrower principal plus contractual-interest memos; (3) every claim economic principal plus contractual-interest memo. Scan every native Group.committed, daily Book, and closing Book before successful preparation, including zero-weight sources. Scan staged runtime Book after each complete atomic group and each post-group daily memo. Group memo channels are not authoritative post-boundary economic changes; exact native daily memos remain a separate non-posting checkpoint.

Combined runtime lanes: staged full GL absolute balances before each complete transaction; actual account cash/equity/cash_floor/capital_deductions at each end-day; actual backbook P/B/allowance/accrued/commitment plus weighted mortgage slots/claim P/A/B at each end-day. The latter excludes duplicated aggregate active placeholder P/B/A. No opposing asset/liability netting can evade the gross domain. Guards run before the transaction's money mutation; a later day-domain failure aborts the stream and cannot publish a manifest. Existing journal/reconciliation gates are still mandatory; no numerical guarantee for every admitted scalar tuple is asserted.

All arithmetic for work/bytes is checked.
