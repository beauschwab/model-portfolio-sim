# Selected finite complete-origin source work

`source.transfer.source_work_policy` may explicitly select
`counted_finite_transfer_contract_factor_work-1`. It selects an algorithmic work
reservation for the existing complete-origin secondary loan owner. It supplies
no factor, monetary checkpoint, tolerance, numeric allowance or new legal policy.
Omission and explicit null retain the historical 250,000 source-factor work floor,
serialized defaults, capacity formulas and financial behavior. Existing source,
coupon, information, credit, acquisition, accounting and settlement policies remain
required. Generated secondary transfers remain unsupported.

The authority is a private immutable Rust borrow of the complete source-income
request. Its origin, original-buyer and current-buyer roles select their exact
raw contracts. Two complete canonical encodings compare the selected contract
to the compiler input; buyer clocks must equal the actual transfer clock. A raw
request cannot deserialize this authority or borrow the generated catalog
authority. The original contract, paired scenario/path identity, source chronology,
original acquisition yield/cost/OAS and full transferred coupon inventories are
still checked by their financial owners. Changing the selector on an existing
source changes its retained identity and requires explicit rebuilding.

The actual full-origin builder runs once per evaluated owner, at the buyer's
information clock. The original and current buyer factors each compile once.
The origin build retains the real pre-transfer principal events and independently
sealed coupon nominal; entitlement100/live principal80 remains100/80. It never
replaces the origin with the buyer's remaining face or a pro-rated final coupon.
Every prospective stopped owner, Physical original proof, pricing bump and
independent native proof owner continues to reserve and execute its own full
origin and both buyer builds. Equal raw contents receive no sharing deduction.

## Shared operation ledger

The selected tier reuses `indexed::work::ContractWorkSummary`, `FactorUseBound`
and `WorkMeter`. For P coupon periods, H dated principal events, C=P+H cash rows,
S fixed/indexed factor segments and Q admitted credit queries, the shared census
includes C² ordering, C²+P²+S(C+P) cash/audit binding, and each observable indexed
period's squared observation lookup inventory. Principal validation/prefix work
is 4P²+32+2H²+4PH+4H. Actual calendar work counts Gregorian-year splits for
ACT/ACT, both interest and observation spans, observation shift and both partial
endpoints. Fixed, simple and compounded indexed arithmetic use the same bounded
calendar, segment and coupon owners as before.

The existing factor-use bound retains Q earning calls; Q or3Q canonical calls
for continuous or observable policy; selected terminal opening calls; and all
pending/terminal scan and recovery-tail multiplicities. This stage deliberately
retains the existing conservative maximum pending/recovery census. It does not
reduce that census because a particular fixture has no realized default or cash.
The actual Q is derived from the prepared interval, boundary and maximum-jump
inventory, separately for every owner. Original-buyer and origin construction
use Q=0. No caller supplies Q or an operation allowance.

Let R be the bounded escaped-UTF8 structural source size with the shared metadata
expansion; O the bounded source/segment output size; Y the calendar work; and N
the sum of period, observation, segment, ordering, binding, validation, earned,
canonical, pending and terminal steps. The selected source work is

`16*(3R) + O + 256*Y + 128*N`.

The 3R input inventory includes both canonical equality scans and the actual
builder input. The meter records the actual canonical byte lengths, actual
builder/serialized output bytes, construction operations and subsequent query
families; exceeding any family fails closed. String bytes, JSON escaping,
metadata and all numeric cells are bounded explicitly; no average string/hash
cost or observed-fixture operation count determines admission. Transfer metadata,
origin/coupon reconciliation, credit/carry/accounting, graph reductions, original
proofs and complete journals retain their separate existing reservations.
