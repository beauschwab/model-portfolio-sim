# Ordinary fixed commercial fee cut

This local extension passes native packet execution, independent raw/source/journal
replay and durable publication with rebuilt release artifacts. The full regression
matrix remains required before release acceptance.

The unchanged `commercial-candidate-holding-journal-1` example becomes a cut request
by selecting `commercial-cut-mixed-journal-1` and copying the complete completed
candidate to the revised candidate. All nine original/current physical/pricing/bump
loan-and-fee owners on each side survive, including fee service, acquired-cost
releases, gross rights and the full 45-day tail. The example has 18 complete proofs.
Exercise, generated credit policy, original-physical acquisition and transferred
fee-right owners remain outside this fixed inventory.

## Capacity and work

Exhaustive native ownership inventories cover fee request labels, event groups,
postings, both snapshots, path clocks, cash events, acquired-cost allocations and
all retained vector/string capacity. Prospective construction includes raw clones,
prefix and full service replays, JSON serialization, sorting and growth overlap.
The native inventory must fit the portable raw-dimensional allowance before graph
construction. The independent verifier calculates that allowance from the raw
request, including the separate fee-income coefficient and fee identity rows.

Capture and resume reserve output for the days each phase executes. Their complete
source groups, snapshot bounds and dictionaries remain retained even at zero
participation. The unpublished prefix still constructs every financial row, report and dictionary.
Its flush visits and funds every dropped JSON cell, key and string without numeric
formatting or byte serialization. Full structural scan work remains reserved before
execution. Journal columns reset and row-vector buffers retain their high-water
capacity. After discarding those rows, row-vector, journal-column and
table-container capacities remain reserved. Prefix Value trees are no longer live.
The immutable prefix is serialized once into a bounded 4-MiB buffer, compacted with
old/new allocation overlap reserved, and compared against the revised source.
The private comparison uses fixed tuple slots for every loan group, loan snapshot,
fee event and fee state field. Exhaustive native destructuring rejects added fields
at compile time until their comparison slot is supplied. Optional zero fee balances
retain separate slots. Public financial proofs keep their original named fields;
no financial amount is reconstructed from this comparison encoding.

The original work/capacity ceilings remain 32 million/128 MiB for the joined route
and 8 million/32 MiB for the sequential component. The complete fee example currently
uses 31,466,307 joined work units and reserves 131,340,256 bytes. Its component uses
6,527,613 work units and reserves 33,435,259 bytes. These are requested-heap and work
allowances, not process RSS guarantees. Some larger or differently shaped fee
requests still reject; no fitting, source pruning or automatic cap increase occurs.
The original no-fee fixture also passes unchanged.

## Verification and publication

Independent verification replays all sources, original quotes, observed prefix,
cut opening, ordered future postings and gross closing. Selected fee proofs cannot
be null. Tampered raw fees, omitted original/current proofs, changed fee cash,
resource receipts and persisted gross rights must reject. Zero allocation never
removes unweighted source evidence.

The explicit source-bound endpoint retains its bounded eight-predecessor chain,
advancing-date and final SQL fences. Fee predecessors receive version 3 execution
evidence with separate gross-fee matching. The native producer continues to report
no independent publication or predecessor authority. Stored receipts are compared
to fresh replay; they cannot grant authority by themselves.

Current local evidence: the original no-fee packet and complete fee packets at
seven cut dates, including dates after repayment and fee settlement, pass. All 84
ledger unit tests and the 63-test independent admission/replay/transport gate pass.
After the final verifier correction, all 15 focused fee tests and ten rebuilt-artifact
worker publication/chain/restart/failure-fence tests pass. The separate full regression
run for commit `c358e45` excludes this extension. These results do not establish observed
predictive accuracy, reviewed accounting/regulatory policy approval, complete
mixed-book scale acceptance or deployment.

The initial worker run exposed an advancing-cut refusal at 8,010,659 component
work. Its output and independent reproduction are retained. Complete compact
comparison and funded discard traversal close that refusal without changing caps
or accounting. A later worker run exposed a separate verifier error after day 30:
path reports are sparse, although daily loan and fee state continues through day 45.
Advanced-prefix verification now uses the independently verified complete horizon
and retains the original sparse report coverage. It still rejects cuts at or beyond
the complete tail. Native source and release artifacts were unchanged by this
verifier-only correction; the failed run is retained separately.
Native exit-2 rejections have a separate structured error channel; transport rejects
partial output before success decoding. Four transport failure controls pass.
