## Runtime, storage and publication

A selected HTTP entry records its clock before raw body formatting. The accepted deadline is saved before enqueue; queue waiting and every retry consume that same deadline. Worker clocks and returned execution metadata cannot extend it. Each calculation captures one executable path/hash, checks the current source/code/workspace bundle, owns one child process and rechecks the captured path/hash after native return and JSON decoding. Missing or changed native artifacts refuse execution; no Python financial fallback exists.

The current selected public transport provides a process watchdog plus independent verification/publication cancellation probes. It does **not** expose a caller-cooperative native per-call control capability for these schema names. Contained native Control tests establish native cooperative behavior in the proof only; killing a child is not that evidence.

Selected raw input is capped at 2 MiB and native output at 32 MiB. Native graph preflight independently charges every original/current path, raw metadata, projection, price/risk array and complete tail under its existing 8M-work/128MiB component limits. Dictionary expansion is checked one row at a time. Identical content-addressed tables can share object bytes, but every decoded appearance is charged. These are component bounds, not an aggregate process RSS or scale-acceptance claim. Ordinary inherited workspace hydration remains the existing worker contract.
